# Business Model — Klear Karma v2

## One-Line
A trust-first marketplace connecting healing seekers with community-verified alternative practitioners in India.

## How It Works

```
Seeker searches → Discovers practitioner → Books session → Pays via app → Attends → Reviews
                                                              ↓
                                              Platform takes 20-30% commission
```

## Revenue Streams

| Stream | Model | MVP Priority |
|--------|-------|:---:|
| **Booking Commission** | 20-30% per session (sliding by category) | ✅ Core |
| **Practitioner Subscription** | ₹2,000/mo for premium visibility + analytics | ✅ Phase 2 |
| **Seeker Pass** | ₹499/mo for priority booking + discounts | ⏳ Phase 3 |

### Commission Rate Table

| Modality Category | Commission Rate | Rationale |
|-------------------|:-:|---|
| Massage / Body Work | 25% | High volume, moderate price |
| Yoga / Meditation | 20% | Price-sensitive segment |
| Reiki / Energy Work | 30% | Higher margin, trust-dependent |
| Ayurveda Consultation | 25% | Medium volume |
| Sound / Crystal Healing | 30% | Niche, premium |
| Life Coaching | 25% | Repeat sessions common |

## Value Proposition

### For Seekers
- **Trust**: See verified credentials, peer reviews, session outcomes
- **Convenience**: Book in 3 taps, pay securely, get reminders
- **Discovery**: Find practitioners by modality, location, rating, availability

### For Practitioners
- **Client Acquisition**: No upfront marketing cost, pay only on completed bookings
- **Professional Tools**: Calendar, booking management, earnings dashboard
- **Credibility**: Verified badge, public review profile, community standing

## Market Context (India)

- Wellness services market: ~₹1.5 lakh crore (growing 20%+ CAGR)
- No dominant vertical marketplace for alternative healing
- Closest analogs: Practo (doctors), Urban Company (home services) — neither focuses on holistic healing
- 500,000+ independent alternative practitioners with zero digital booking infrastructure

## Competitive Advantage

1. **Verification layer** — Multi-step practitioner verification (credentials, peer endorsement, session auditing)
2. **Outcome tracking** — Seekers log session outcomes creating a feedback loop
3. **Modality expertise** — Platform designed for healing sessions (not generic appointments)
4. **Community-first trust** — Reviews + community endorsements > paid advertising

## Unit Economics Target (Per Booking)

| Metric | Value |
|--------|-------|
| Average session price | ₹2,000 |
| Platform commission (25%) | ₹500 |
| Payment gateway fee (~2%) | ₹40 |
| **Net revenue per booking** | **₹460** |
| Target monthly bookings (MVP) | 500 |
| **Monthly revenue target** | **₹2.3L** |

## What We Are NOT

- Not a medical platform (no diagnoses, no prescriptions)
- Not a content/social network (no feeds, no reels)
- Not a biofield measurement tool (no pseudoscience claims)
- Not a SaaS tool for clinics (single practitioners, not enterprises)
